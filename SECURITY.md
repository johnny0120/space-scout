# Security Policy

If you discover a vulnerability or secret exposure in Space Scout, please report it
privately through [GitHub's private vulnerability reporting form](https://github.com/johnny0120/space-scout/security/advisories/new).
If the link is unavailable, contact the maintainer through the `johnny0120` GitHub profile
and do not publish sensitive details in an issue.

Include:

- A short description of the issue
- Affected version or commit
- Reproduction steps
- Any suggested fix or mitigation

Do not publish sensitive details in a public issue or pull request.

The latest release is the supported version. Security reports are acknowledged within
14 days when possible; fixes and coordinated disclosure timelines depend on severity and
the affected platforms.
